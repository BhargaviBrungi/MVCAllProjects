## ASP.NET MVC – Multiple Projects Collection

This repository contains a collection of web applications developed using **ASP.NET MVC 5, C#, SQL Server, HTML, CSS, and JavaScript**, demonstrating practical knowledge of full-stack web development.

### Projects Included:

**1. Hotel Registration System**
Developed a hotel booking and registration application with customer management, room-type and amenities selection, automatic cost calculation, CRUD operations, and SQL Server integration.

**2. Weather Information Application**
Integrated the OpenWeatherMap REST API using HttpClient and JSON parsing to display real-time weather information, including temperature, humidity, and weather conditions based on city searches.

**3. QR Code Generator**
Created a web application using the QRCoder library to generate QR codes from text and URLs, with instant preview and download functionality.

**4. Utility Applications Suite**
Developed multiple utilities, including Calculator, Calendar, CAPTCHA Validation, and Graphical Charts, demonstrating C# programming logic, JavaScript interactivity, and form validation.

### Technologies Used:
- ASP.NET MVC 5
- C#
- SQL Server
- HTML5 and CSS3
- JavaScript
- REST API
- HttpClient
- QRCoder Library

These projects demonstrate my practical experience in web application development, database management, API integration, CRUD operations, and responsive user interface design.
